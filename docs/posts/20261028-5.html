ソフトウェアテストの専門会社で、売上は4期連続で増え119億円になりましたが、営業利益は9億円台で横ばいです。予想PERは約15.4倍、PBRは約2.6倍、配当利回りは約0.85%で、数字の上で目立って割安とは言えず、2027年3月期の第1四半期は営業損失でした。流動比率約2.09倍などの財務の余裕が強みです。最低購入代金は約4.7万円です。

事業内容

一言でいうと: 「作ったソフトやアプリが、ちゃんと動くかを確かめる専門会社」です。たとえるなら、新車を売り出す前に、あらゆる道を走って不具合を探す試験走行のプロ集団。システム開発会社や事業会社から、ソフトウェアのテスト(検証)を請け負い、1,342名の稼働エンジニアが現場で確認作業をします。このテスト事業が売上の約85%を占め、ほかにWeb・モバイルアプリの開発(約12%)と、アプリの弱点を探す脆弱性診断(約2%)があります。生成AIでテストの設計を自動化するツールも自社で開発中です。

各事業の中身

  • ソフトウェアテスト: テスト計画からテスト実施、結果のまとめ(サマリレポート)までを、開発する側から独立した第三者の立場で請け負います。企業向け(エンタープライズ系)の大きなシステムに力を入れています。会社の資料では、年間の案件数は7,489件(前年より1,846件増)、ツールを使った案件は前年より764件増え、月間の単価は85.2万円(前年より4.2万円増)です(単価の算定単位は資料に明記がなく未確認)。年間約7,000プロジェクト、1,300社以上への導入実績があるとしています。
  • 開発: Web・モバイルアプリの開発、システム開発の請負、開発要員の派遣です。2026年3月期は売上が-2.0%でしたが、前期の赤字から黒字に戻りました。
  • セキュリティ: Webアプリやモバイルアプリの弱点(脆弱性)を調べる診断サービスです。売上は小さい(2.91億円)ものの、+34.7%と伸びています。
  • 自社ツール: 生成AIテスト設計ツール「TestScape(テストスケープ)」は、仕様書からテストの観点やテストケースを自動で作り、中間生成物も残すので、設計の根拠を後から確かめられる点が特徴と会社は説明しています。2026年3月に社内で正式運用を始め、2026年5月にシナリオテストの設計にも対応しました。ただし単独での外部販売は予定していません。文書の品質をAIで採点する「QuintSpect(クインスペクト)」は2025年10月にβ版を出し、外販を予定しています。ほかにテスト自動化ツール「T-DASH」があります。

儲けの仕組み

  • ソフトウェアテスト(売上の約85%): 顧客企業からテスト業務を請け負い、委託料を受け取ります。エンジニアが何人、どのくらいの単価で働くかで売上が決まる「人に依存する」(労働集約型の)ビジネスです。会社は、この形から「人に依存しないビジネス」へ移ることを新中期経営計画の中心テーマに置いています。
  • 開発・セキュリティ: 開発は請負や要員派遣の対価、セキュリティは診断サービスの対価が収入です。
  • 契約形態(準委任か請負か)、稼働率、主要顧客の売上構成は確認した資料に記載がなく未確認です。
  • コスト面: 人件費が中心と考えられます(当方の整理)。生成AIツールの開発に3年で12億円を投じる計画で、2027年3月期もAI投資の影響は約4.0億円(AI投資前の営業利益13.7億円と、投資後の予想9.7億円の差、当方の計算)を見込んでいます。

強み・競合

  • 独自のテスト進行基準「QUINTEE」を持ちます。JR東日本情報システムから、ソフトウェアテスト専門会社として初めて「JEISコアパートナー」に認定されました(会社資料)。
  • 単なる人の派遣ではなく、テストの計画・設計・実施・報告までを一括して引き受ける形と、自社ツールを組み合わせる点が特徴だと考えられます(当方の見立て)。
  • 主な競合は、同じ上場の検証会社のSHIFT(3697)などです。SHIFTは時価総額3,017億円(10/27、松井証券)で、規模はバルテスの約30倍です(当方の計算)。ほかにデジタルハーツHD(3676)は、2026年8月にMBO(経営陣による買収)の一環としてTOB価格1,060円が発表されており、結果は未確認です。競合ごとの売上・利益・シェアの比較は未確認です。
  • 会社は、上場しているテスト専門会社の業界占有率を約1%としています(会社資料)。

成長ドライバー

  • IT人材の不足: 会社は、テストを専門業者に任せる動きや、開発の上流工程からテスト会社が関わる動きが増えているとしています。
  • 市場の大きさ: 会社の推定では、日本のソフトウェアテスト市場は約6.2兆円です(2020年のソフトウェア業売上16.7兆円×テスト工程の比率37%という試算)。これは開発の中でテストにかかる費用全体を含む推定で、外部の会社に出される金額ではないため、実際に狙える市場はもっと小さいと考えられます(当方の注記)。また、テストは開発エンジニアの労働時間の約40%を占めるとされています。
  • 2027年3月期の会社予想: 売上141.6億円(+18.6%)、営業利益9.7億円(+5.0%)、経常利益9.5億円(+3.1%)、純利益6.1億円(+6.4%)、配当4円。AI投資の影響を除いた営業利益は13.7億円(+13.8%)です。
  • 新中期経営計画(3か年、2025年6月公表、最終年度は2028年3月期): 売上170.0億円、営業利益18.8億円を目標にしています。生成AIテストツール開発に3年で12億円、M&A(企業買収)などの投資に3年で25億円の計画です。前期(2026年3月期)はM&Aを実行しておらず、2027年3月期は積極的に進める方針です。

広告枠

なぜ今後重要になりそうか

  • AIで作るソフトが増えるほど、「確かめる仕事」の重みが増す可能性: これは当方の見立てで、会社が明言したものではありません。AIがコードを書く量が増えると、その出来を確認するテストの量や、仕様どおりかを確かめる難しさも増えると考えられます。会社は、テストが開発エンジニアの労働時間の約40%を占めるとしています。
  • アプリ開発に関心のある読者へ: 開発の「作る」側だけでなく、「確かめる」側にも産業があります。この会社は、仕様書からテストケースを自動生成するTestScape、文書の品質を採点するQuintSpect、テスト自動化のT-DASHを手がけ、アプリの脆弱性診断も行います。ソフト開発の流れの中でテストがどう位置づけられるかを知る実例になります。ただしAIツールの売上や利益への寄与は未確認です。
  • 人に頼る形からの脱却を掲げています: 会社は「人に依存しないビジネス」への転換を方針としていますが、2027年3月期の会社予想でも、AI投資の影響で営業利益の伸びは+5.0%にとどまります。
  • まだ数字には表れていません: 売上は4期連続で増えて119.4億円になりましたが、営業利益は2023年3月期の9.7億円からほぼ横ばい(2026年3月期9.2億円)です。「重要度が増す」は期待であって、実績ではありません。
  • 逆風もあります: 生成AIがテストの設計や実施そのものを自動化すれば、人の稼働に応じて売上が増える今の収益モデルが弱まる可能性もあります(当方の見方で、会社の記載ではありません)。
  • 注目されにくい小型株: 東証グロース市場の銘柄(松井証券以外の情報サイトによる)で、時価総額は約101億円(自己株式を含む発行済株式数で計算)です。代表取締役会長兼社長が37.63%を保有しているという情報があります(出典の掲載時点は未確認)。

リスク

  • 利益が伸び悩んでいる: 営業利益は2023年3月期9.7億円、2024年3月期8.4億円、2025年3月期9.3億円、2026年3月期9.2億円と横ばいです。営業利益率は10.7%(2023年3月期)から7.7%(2026年3月期)に下がりました。

用語メモ

  • ソフトウェアテスト: ソフトウェアやアプリが仕様どおりに動くか、不具合がないかを確かめる作業。
  • 第三者検証: 作った側とは別の会社が、独立した立場でテストすること。
  • 労働集約型: 売上が働く人の数や時間に比例しやすいビジネス。
  • 脆弱性診断: アプリやWebサイトの、攻撃されやすい弱点を調べる検査。
  • M&A: 企業の買収や合併。
  • のれん: 会社を買収したとき、買った値段が相手の純資産を上回った差額。価値が下がると損失(減損)になることがあります。
  • 株主優待: 株を持つ人に、会社が配当とは別に渡す商品券などの特典。
  • 季節性: 時期によって売上や利益が上下する性質。この会社は利益が下期(10〜3月)に偏ります。
  • PER: 株価÷1株あたり利益。低いほど利益に比べて株価が低い状態です。
  • PBR: 株価÷1株あたり純資産。1倍割れは、会社の純資産より株価が低い状態です。
  • 配当利回り: 年間配当÷株価。持っている間にもらえる現金の割合です。
  • 配当性向: 利益のうち配当に回した割合。
  • ROE: 自己資本に対する利益の割合。高いほど資本を効率よく使っています。
  • 単元株: 最低売買単位。ここでは100株です。
  • 時価総額: 株価×発行済み株数。会社全体の値段です。
  • 自己株式: 会社が自社の株を買って持っているもの。発行済み株数に含まれますが、利益や純資産の1株あたりの計算では除く場合があります。
  • 自己資本比率: 総資産のうち返さなくてよいお金の割合。高いほど安定しています。
  • 流動比率: 流動資産÷流動負債。短期の支払い余力を見ます。
  • 営業キャッシュフロー: 本業で実際に増えた現金。利益と一致するとは限りません。
  • 東証グロース市場: 東証の、成長をめざす新しい会社向けの市場です。
