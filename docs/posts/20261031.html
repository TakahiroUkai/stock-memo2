事業内容

一言でいうと: 企業が自社のスマホアプリを、プログラムを書かずに(ノーコードで)作って運用できるクラウドサービス「Yappli(ヤプリ)」の会社です。たとえるなら、お店が「自分のアプリ」を持ちたいとき、設計図から作る建築会社ではなく、組み立て式の部屋と管理人サービスを月額で貸す不動産会社のようなもの。小売・飲食・人材・大学・労働組合などのアプリを、約960件の契約で運営しています(2026年6月末)。

事業の構成(2026年12月期 中間期、1〜6月累計): 事業は単一セグメント(デジタルプラットフォーム事業)で、セグメント別の売上はありません。代わりに中間期の収益構造を示します。

各サービスの中身

  • Yappli: ノーコードでiOS・Android両方のアプリを作り、お知らせ配信や会員証、クーポン、ポイントなどを運用します。累計ダウンロードは3億DLを超え、飲食業界からの引き合いが多いと説明されています。
  • Yappli UNITE: 社内向けのアプリ。社員向けのお知らせ、eラーニング、クイズ機能などがあり、人材・労働組合などの導入事例があります。
  • Yappli WebX: AIを使ってWebサイトを作り運用するシステム。AIによる多言語翻訳機能を追加しました。
  • Yappli MiniApp: 2026年2月にリリースした、LINEミニアプリの管理・運用サービス。LINEヤフーの「Technology Partner(LINEミニアプリ部門)」に早期認定されたと説明しています。
  • Yappli MobileOrder: 2025年11月に子会社化したヤプリフードコネクトのモバイルオーダー(スマホ注文)サービス。

儲けの仕組み

  • 誰に何を売るか: 企業に、アプリの開発・運用の基盤を月額で提供します(ストック売上)。あわせて、アプリの制作やマーケティング支援を受注します(フロー売上、プロフェッショナルサービス)。
  • 継続性: 契約が続くかぎり毎月の利用料が入ります。解約率は過去12か月平均で0.90%と低い水準です。平均月額利用料は47万円で、契約数は960件です。
  • コスト: 売上原価は売上の31.7%、販管費は49.0%でした。販管費には広告宣伝費(2Q 1.87億円)と人件費(2Q 前年同期比+9.9%)が含まれ、会社は広告宣伝費を3Q・4Qも2Q並みと見込んでいます。
  • 投資効率: LTV/CAC(顧客が生む利益の合計÷獲得コスト)は過去12か月で6.1倍と説明されています。料金プランの価格表は未確認です。

用語メモ

  • ノーコード: プログラムを書かずに、画面の操作でアプリやサービスを作れること。
  • SaaS: ソフトをインターネット経由で月額などで使えるサービス。
  • ARR: 年間の継続収益。毎月の利用料から見込める1年分の売上の目安です。
  • ストック売上/フロー売上: 毎月積み上がる継続課金の売上と、制作などその都度の売上。
  • 解約率: 契約をやめた顧客の割合。低いほど安定した収益になります。
  • LTV/CAC: 顧客が生む利益の合計(LTV)を、顧客を獲得するコスト(CAC)で割った数。大きいほど効率がよい状態です。
  • LINEミニアプリ: LINEの中で動く小さなアプリ。
  • PER: 株価÷1株あたり利益。低いほど利益に比べて株価が低い状態です。
  • PBR: 株価÷1株あたり純資産。1倍割れは、純資産より株価が低い状態です。
  • 配当利回り: 年間配当÷株価。持っている間にもらえる現金の割合です。
  • 配当性向: 利益のうち配当に回した割合。
  • ROE: 自己資本に対する利益の割合。高いほど資本を効率よく使っています。
  • 単元株: 最低売買単位。ここでは100株です。
  • 時価総額: 株価×発行済み株数。会社全体の値段です。
  • 自己資本比率: 総資産のうち返さなくてよいお金の割合。高いほど安定しています。
  • 流動比率: 流動資産÷流動負債。短期の支払い余力を見ます。
  • 東証グロース市場: 東証の、成長中の新しい会社向けの市場。値動きが大きくなりやすいとされます。
